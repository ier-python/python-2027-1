crudas = ["23,5", "25,1", "22,8", "24,9"]temperaturas = []                          # 1. lista vacíafor c in crudas:                           # 2. recorrer    valor = float(c.replace(",", "."))     # 3. procesar    temperaturas.append(valor)             # 4. acumularprint(temperaturas)

Compáralo con las cadenas de la sesión pasada:| | Cadenas | Listas ||—|—|—|| s.replace(",", ".") | devuelve una nueva, la original no cambia | — || lista.append(x) | — | modifica la lista, no devuelve nada |Las cadenas son inmutables. 10.5 2.3 append vs extend### PREDICE ✍️¿Cuánto vale len(a) al final?

a = [1, 2]b = [3, 4]a.append(b)print(a)print(len(a))

Son 3, no 4. .append() mete la lista completa como un solo elemento: te queda una lista dentro de otra.Para juntar mediciones necesitas .extend():

a = [1, 2]b = [3, 4]a.extend(b)print(a, len(a))

t = [23.5, 25.1, 22.8, 24.9]print("n:       ", len(t))print("suma:    ", sum(t))print("mínima:  ", min(t))print("máxima:  ", max(t))print("promedio:", sum(t) / len(t))print("rango:   ", max(t) - min(t))

Con formato legible:

print(f"promedio: {sum(t) / len(t):.2f} °C")print(f"rango:    {max(t) - min(t):.1f} °C")

vacia = []if len(vacia) > 0:    print(sum(vacia) / len(vacia))else:    print("sin datos válidos")

***# Bloque 4 — Ordenar ⏱ 12 min### PREDICE ✍️¿Qué imprime esto?

t = [25.1, 22.8, 27.0, 23.5]print(t.sort())

Imprime None..sort() ordena en el lugar y no devuelve nada. sorted() deja la original intacta y devuelve una copia ordenada.

t = [25.1, 22.8, 27.0, 23.5]print(sorted(t))                  # copia ordenadaprint(sorted(t, reverse=True))    # de mayor a menorprint(t)                          # la original no se tocó
t.sort()                          # ahora sí, en el lugarprint(t)t.reverse()                       # invertir, también en el lugarprint(t)

Trampa clásica: t = t.sort() deja t valiendo None, y el error truena mucho después, en otra línea, con un mensaje que no menciona sort. Escribe t.sort() a secas, o t = sorted(t).Aplica al resto: .append(), .extend(), .insert(), .remove() y .reverse() también devuelven None.

sorted() también funciona sobre cadenas, y por eso el formato ISO importa:

print(sorted(["2025-11-02", "2025-03-14", "2025-07-01"]))   # ordena bienprint(sorted(["2/11/2025", "14/3/2025", "1/7/2025"]))       # ordena mal

***# Bloque 5 — Recorrer ⏱ 13 min## 5.1 zip() — dos listas en paralelo

fechas = ["2025-03-14", "2025-03-15", "2025-03-16"]temps  = [23.5, 25.1, 22.8]for f, t in zip(fechas, temps):    print(f"{f}\t{t}")

Si las listas tienen distinta longitud, zip se detiene en la más corta, sin avisar. Es una fuente clásica de datos perdidos en silencio.## 5.2 enumerate() — con la posición

10.6 5.3 RebanadasSe rebanan igual que las cadenas, y siempre devuelven una lista nueva:

serie = [23.5, 25.1, 22.8, 24.9, 26.3, 22.1]print(serie[:3])      # primeros tresprint(serie[-2:])     # últimos dosprint(serie[1:4])     # de la posición 1 a la 3print(serie[::2])     # uno sí, uno noprint(serie[::-1])    # invertida

10.7 5.4 Copia vs referencia### PREDICE ✍️¿Qué imprime print(a) al final?

a = [1, 2, 3]b = ab.append(99)print(a)

Imprime [1, 2, 3, 99].b = a no copia la lista: le pone un segundo nombre a la misma lista. Para copiar de verdad:

a = [1, 2, 3]c = a.copy()c.append(77)print(a, c)print(a is c)      # ¿son la misma lista en memoria?

Este es el error más caro de las listas y aparece en proyectos reales todo el tiempo. Cuando dos listas “se modifican solas”, es esto. Ojo: b = a sí es lo que quieres cuando no vas a modificar nada.

Solución

fechas = []temps = []for linea in crudo.splitlines():    linea = linea.strip()    if linea == "":        continue    if linea.startswith("#"):        continue    if linea.startswith("fecha"):        continue    campos = linea.split("\t")    fecha_cruda = campos[0]    temp_cruda = campos[1]    if temp_cruda == "NA":        print(f"omitido: {fecha_cruda}")        continue    dia, mes, anio = fecha_cruda.split("/")    fechas.append(f"{anio}-{mes.zfill(2)}-{dia.zfill(2)}")    temps.append(float(temp_cruda.replace(",", ".")))print()for f, t in zip(fechas, temps):    print(f"{f:<16}{t:.1f}")print()print(f"n        = {len(temps)}")print(f"promedio = {sum(temps) / len(temps):.2f} °C")print(f"máxima   = {max(temps):.1f} °C el {fechas[temps.index(max(temps))]}")

Compara ese resultado con el crudo de la primera celda.Ese texto pegajoso de la sesión pasada ahora es un número. Eso es limpieza de datos, y es la mitad del trabajo de cualquier proyecto real. El resto del curso son variantes más rápidas de este mismo ciclo.
