***# Bloque 1 — Extremos y pedazos ⏱ 20 min## 1.1 strip() — quitar la basura de los extremos

dato = "   23.5 \n"print(repr(dato), len(dato))limpio = dato.strip()print(repr(limpio), len(limpio))

.strip() quita espacios, tabuladores y saltos de ambos extremos, nunca de en medio.Variantes: .lstrip() solo por la izquierda, .rstrip() solo por la derecha, y .strip("#") quita los caracteres que le indiques.

print(repr("  30.2  ".lstrip()))print(repr("  30.2  ".rstrip()))print(repr("###30.2###".strip("#")))

Casi siempre va antes de convertir a número:

print(float("  23.5  "))    # float() tolera espaciosprint(float("23.5 °C"))     # pero no una unidad pegada -> ValueError

☝️ Lee el error completo. La última línea dice el tipo (ValueError) y el motivo. Los errores de Python se leen de abajo hacia arriba.

9.2 1.2 split() — partir en pedazosLas fechas en español van del día al año. Los sistemas de datos las quieren al revés.

fecha = "14/03/2025"partes = fecha.split("/")print(partes)

.split(separador) corta cada vez que encuentra el separador y devuelve una lista. El separador desaparece.A cada pedazo se llega por su posición, empezando en 0:

print(partes[0], partes[1], partes[2])print(partes[-1])        # el último

Pero como sabemos que son exactamente tres pedazos, conviene desempaquetar:

dia, mes, anio = fecha.split("/")print(dia, mes, anio)print(f"{anio}-{mes}-{dia}")

El formato aaaa-mm-dd se llama ISO. Su ventaja: se ordena alfabéticamente igual que cronológicamente.

9.3 1.3 zfill() — los ceros que nadie escribeNuestro archivo trae 14/3/2025, no 14/03/2025. Si no lo arreglas, "2025-3-14" se ordena mal frente a "2025-11-02".

print("3".zfill(2))      # '03'print("03".zfill(2))     # '03'   ya lo tenía, no hace nadaprint("123".zfill(2))    # '123'  nunca recorta

***# Bloque 2 — Sustituir ⏱ 15 min## 2.1 replace()Nuestro archivo trae 23,5 con coma decimal. float() no la entiende.

temp = "23,5"print(float(temp.replace(",", ".")))

.replace(viejo, nuevo) sustituye todas las apariciones. Se pueden encadenar:

monto = "$1,234.50"print(float(monto.replace("$", "").replace(",", "")))

Cuando hay separador de miles y coma decimal, el orden importa:

consumo = "1.845,30"                  # mil ochocientos cuarenta y cincopaso1 = consumo.replace(".", "")      # '1845,30'  fuera el separador de milespaso2 = paso1.replace(",", ".")       # '1845.30'  la coma pasa a puntoprint(float(paso2))

Con un tercer argumento limitas cuántas sustituciones hace:

print("1.234.567".replace(".", "", 1))

9.4 2.2 Inmutabilidad### PREDICE ✍️¿Qué imprime esto? Escríbelo en papel antes de ejecutar.

s = "23,5"s.replace(",", ".")print(s)

Sigue siendo 23,5.Las cadenas son inmutables: .replace() no modifica nada, devuelve una cadena nueva. Si no la guardas, se pierde.

s = "23,5"s = s.replace(",", ".")   # así síprint(s)

Esto aplica a todos los métodos de cadenas: strip, replace, upper, title… ninguno modifica la original. Guarda siempre el resultado.

***# Bloque 3 — Muchas líneas ⏱ 20 min## 3.1 splitlines()

bloque = "14/3/2025,23.5\n15/3/2025,25.1\n16/3/2025,22.8"lineas = bloque.splitlines()print(lineas)

Es mejor que .split("\n"), porque este último deja un elemento vacío si el texto termina con salto de línea:

print("a\nb\n".split("\n"))     # ['a', 'b', '']  <- sobraprint("a\nb\n".splitlines())    # ['a', 'b']      <- correcto

El patrón base de todo lector de datos: partir en líneas → partir cada línea en campos.

for linea in lineas:    fecha, temp = linea.split(",")    print(fecha, "->", float(temp))

9.5 3.2 split("\t") y split() a secasNuestro archivo usa tabuladores. Y ojo con esta diferencia:

linea = "TEMIXCO   2025-03-14    23.5"print(linea.split())        # agrupa los espaciosprint(linea.split(" "))     # ¡uno por cada espacio!

.split() sin argumento parte por cualquier cantidad de espacios, tabuladores o saltos, y descarta los vacíos.- Columnas exactas de una hoja de cálculo → .split("\t")- Columnas alineadas a ojo, con anchos irregulares → .split()

9.6 3.3 Filtrar líneasUn archivo real trae comentarios, encabezados y renglones vacíos. Se descartan al inicio del ciclo con continue:

for linea in crudo.splitlines():    linea = linea.strip()    if linea == "":                  # renglón vacío        continue    if linea.startswith("#"):        # comentario        continue    if linea.startswith("fecha"):    # encabezado        continue    print(repr(linea))

startswith, endswith e in devuelven True o False:

print("2025-03-14".startswith("2025"))print("datos.csv".endswith(".csv"))print("NA" in "15/3/2025,NA,58")

startswith también acepta varias opciones a la vez:

print("// comentario".startswith(("#", "//", ";")))

Solución

for linea in crudo.splitlines():    linea = linea.strip()    if linea == "":        continue    if linea.startswith("#"):        continue    if linea.startswith("fecha"):        continue    campos = linea.split("\t")    fecha_cruda = campos[0]    temp_cruda = campos[1]    hum_cruda = campos[2]    if temp_cruda == "NA":        print(f"omitido: {fecha_cruda}")        continue    dia, mes, anio = fecha_cruda.split("/")    fecha = f"{anio}-{mes.zfill(2)}-{dia.zfill(2)}"    temp = float(temp_cruda.replace(",", "."))    hum = int(hum_cruda)    print(f"{fecha:<14}{temp:>6.1f}{hum:>6d}")
