Estructuras de control

Clase 007 · 007_listas_estructuras — Las tres estructuras que controlan el flujo de un programa: for, while e if/else. Cierras filtrando una lista de variables, primero con un ciclo y luego con una comprensión de listas.

De C a Python

En otros lenguajes, el for se escribe con contador, condición e incremento, y el bloque va entre llaves:

for (i = 0; i <= 10; i = i + 1) {
    /* dentro del for */
}

En Python no existe nada de eso: se recorre directamente una colección y el bloque se define con indentación.

for e indentación

En Python el bloque del for no lleva llaves: lo define la indentación. Todo lo indentado se repite; la primera línea sin indentar ya está afuera.

for i in range(2):
    print(i)
    print(i+1)
    print(i+1)
    print("fin de la estructura")

Filtrar una lista

Patrón clásico: recorres variables y te quedas solo con las que contienen "Ti_", acumulándolas en una lista nueva con append.

variables = ["Ti_sala","ach","Ti_cafe","temperatura"]
interes = []
for variable in variables:
    if "Ti_" in variable:
        interes.append(variable)
interes
['Ti_sala', 'Ti_cafe']

Comprensión de listas

La misma operación en una sola línea: [variable for variable in variables if "Ti_" in variable]. Es el modo pythonico de construir una lista filtrada.

[variable for variable in variables if "Ti_" in variable]
['Ti_sala', 'Ti_cafe']
[variable  for variable in variables if "Ti_" in variable]
['Ti_sala', 'Ti_cafe']
