Métodos de cadenas: split, strip y replace

Clase 005 · 005_manipulacion_cadenas — El preámbulo del ETL: tomas cadenas con separadores mezclados (comas, tabuladores, saltos de línea), como las que entrega un adquisidor de datos, y las partes y limpias con métodos de cadenas.

split con distintos separadores

split(sep=...) parte la cadena donde aparece el separador y regresa una lista. Como el resultado es una lista, puedes indexarla y volver a partir: eso hacen las celdas encadenadas.

cadena = "tiempo,temperatura,\tvelocidad viento, direccion viento\t"
print(cadena)
tiempo,temperatura, velocidad viento, direccion viento  
cadena.split(sep="\t")
['tiempo,temperatura,', 'velocidad viento, direccion viento', '']
cadena.split(sep=",")
['tiempo', 'temperatura', '\tvelocidad viento', ' direccion viento\t']
oracion = "esta, es, una\tlista,combinada#caracteres"
oracion.split(sep=",")
['esta', ' es', ' una\tlista', 'combinada#caracteres']
oracion.split(sep=",")[2].split(sep="\t")
[' una', 'lista']
oracion.split(sep=",")[2].split(sep="\t")[0]
' una'

Texto multilínea

Con triple comilla una cadena puede abarcar varias líneas; partiéndola por "\n" obtienes una lista de renglones, y con una rebanada descartas los extremos vacíos.

parrafo = '''
Esta es una historia
de como se aprendio Python
en, el, IER, de, la, UNAM
'''
print(parrafo)

Esta es una historia
de como se aprendio Python
en, el, IER, de, la, UNAM

parrafo.split(sep="\n")[1:-1:]
['Esta es una historia',
 'de como se aprendio Python',
 'en, el, IER, de, la, UNAM']

Limpiar espacios: la familia strip

lstrip() quita espacios a la izquierda, rstrip() a la derecha y strip() en ambos lados. Son el primer paso típico al limpiar datos crudos.

texto_raro = " Este, es, un, texto, raro"
texto_raro.split(",")
[' Este', ' es', ' un', ' texto', ' raro']
texto_raro
' Este, es, un, texto, raro'
texto_raro.lstrip()
'Este, es, un, texto, raro'
texto_raro.rstrip()
' Este, es, un, texto, raro'
texto_raro.lstrip().rstrip()
'Este, es, un, texto, raro'
texto_raro.strip()
'Este, es, un, texto, raro'

replace

replace(viejo, nuevo) sustituye todas las apariciones. Recuerda: regresa una cadena nueva, el original queda intacto (compruébalo en la última celda).

parrafo = '''
Esta es una historia
de como se aprendio Python
en, el, IER, de, la, UNAM
'''
parrafo.replace("\n","")
'Esta es una historiade como se aprendio Pythonen, el, IER, de, la, UNAM'
parrafo
'\nEsta es una historia\nde como se aprendio Python\nen, el, IER, de, la, UNAM\n'
